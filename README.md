### 🎮 О модпаке

**Ultimate Optimizations: Ultra Boost Edition** — это продвинутый технический модпак, созданный для тех, кто не готов выбирать между производительностью и качеством картинки. 

Главная цель сборки — поймать идеальный баланс: **максимизировать ваш FPS, обеспечить невероятно плавный и плоский график фреймтайма и полностью устранить фризы**, сохранив при этом сочную и качественную визуальную составляющую.

#### ✨ Что внутри?
* **Идеальный фреймтайм:** Стабильный график фреймтайма без резких пиков. Забудьте о микро-фризах и подергиваниях во время тяжелых сцен.
* **Умный буст FPS:** Комплексные технические оптимизации движка и менеджмента памяти, выжимающие максимум из вашего железа.
* **Встроенные шейдеры:** Никакой ручной настройки. Пре-оптимизированные шейдеры уже встроены в пак, обеспечивая **потрясающую кинематографичную картинку** без удушения вашего железа.

### ⏱️ Время загрузки модпака

Скорость запуска сильно зависит от скорости вашего накопителя. Вот реальные показатели:

#### 🔄 Первый запуск (Инициализация и генерация кэша)
* **На SSD:** **Около 1 минуты**
* **На жестком диске (HDD):** **Около 3 минут**
* **Почему?** Это абсолютно нормальное поведение. При самом первом запуске модпак анализирует конфигурацию вашего железа, оптимизирует файлы конфигурации под вашу систему и создает начальные кэши макетов.

#### ⚡ Последующие запуски (На разных дисках)
* **Топовые NVMe SSD (класса Samsung 990 Pro):** Занимает всего **от 20 до 30 секунд**.
* **Стандартные SATA/M.2 SSD (Большинство дисков):** Занимает около **30–45 секунд**.
* **Жесткие диски (HDD):** Загрузка может занимать **от 40 секунд до 2 минут**. Это связано с архитектурными ограничениями HDD — им физически требуется больше времени для поиска и чтения фрагментированных данных.

⚠️ **Если вы используете быстрый SSD, но загрузка все равно длится дольше 45 секунд:**
Возможно, вы столкнулись с техническим конфликтом. Если это произошло, пожалуйста, **откройте тикет во вкладке Issues** здесь на GitHub. Я изучу ваши логи и постараюсь помочь решить проблему!

### 🧠 Требования к RAM, VRAM и Java

#### 💻 1. Выделение оперативной памяти (System RAM)
Выделяйте память в лаунчере с умом. Слишком много оперативной памяти может только навредить производительности!

| Выделенная RAM | Для чего лучше всего подходит |
| :--- | :--- |
| **4 GB** | **Абсолютный минимум.** Пак запустится, но придется использовать минимальные настройки. |
| **6 GB** | **Рекомендуется для слабых ПК.** Оптимальный баланс для не самых мощных сборок. |
| **8 GB** | **Для шейдеров и высокой прорисовки.** Идеально для плавной работы шейдеров Solas. |
| **12 GB** | **Для максимального FPS.** Необходимо, чтобы приблизиться к показателям нашего стресс-теста на мощном ПК. |
| **16 GB** | **Абсолютный максимальный порог.** Запас для самых тяжелых игровых сценариев. |
| **⚠️ Выше 16 GB** | **СТРОГО НЕ РЕКОМЕНДУЕТСЯ!** Сборщик мусора Java (Garbage Collector) начнет испытывать проблемы с управлением огромным размером кучи (heap), что приведет к сильному падению FPS и постоянным фризам. |

#### 🎬 2. Видеопамять (VRAM)
*Видеопамять управляется графическим движком автоматически; **вам не нужно указывать или принудительно задавать её объем вручную** в настройках лаунчера.*

* **4 GB VRAM** — Минимальное техническое требование для стабильной работы модпака.
* **8 GB VRAM** — Рекомендуемый объем для комфортной игры с улучшенной графикой.
* **12 GB VRAM** — Требуется для достижения результатов, близких к нашим тестам High-End ПК.
* **16 GB VRAM** — Для еще лучшей стабильности и более высокого минимального фреймрейта.
* **24 – 32 GB VRAM** — Абсолютный максимум для бескомпромиссных ультра-настроек.

#### ☕ 3. Рекомендации по Java Runtime
* 🔥 **Лучший выбор:** Настоятельно рекомендуется установить **GraalVM Community (Всегда используйте последнюю версию)**. Это наиболее стабильная и производительная среда выполнения Java. Весь модпак целенаправленно оптимизировался и полировался именно под GraalVM!
* 📊 **Поддерживаемые версии:** Пак полноценно поддерживает и нативно работает на **Java 25 и выше**.
* 🛑 **Критическое примечание:** Всё, что ниже Java 25, **совершенно не поддерживается**. Игровой движок не сможет выполниться и откажется запускаться.
